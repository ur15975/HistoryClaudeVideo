# 天幕风格指南

本项目的目标画风参考 TV 动画《天幕的魔女》（原作トマトスープ《天幕のジャードゥーガル》，Science SARU 制作，2026 年 7 月播出，总监督山田尚子、监督 Abel Góngora）。我们把它的视觉语言移植到中国历史题材上。

## 1. 视觉

**平面与纵深并存。** 原作参考伊斯兰细密画：平面化的色块、左右对称的建筑、几乎没有透视的人物。中国题材的对应物是**汉画像砖、敦煌壁画、青绿山水和古舆图**。

- **构图**：宫殿、城门、帐内一律正面、左右对称；地形用层叠的剪影（远山 → 中景 → 前景）表现纵深；镜头以缓慢推拉和平移为主，少用旋转。
- **色彩**：低饱和的矿物色——朱砂 `#c2452d`、赭石 `#b8763e`、石青 `#3e6f8c`、石绿 `#5f9c86`、靛蓝 `#2f4a6d`、金 `#d6a84a`，底色是暖纸色 `#efe6d2`。夜景用深靛蓝 `#18203a`，不用纯黑。
- **线条**：深褐色细线勾边（`#3b2f29`），皮肤用偏红的色线（`#8a5443`）。平涂为主，阴影最多一层。
- **质感**：全片叠一层宣纸纹理和轻微胶片颗粒（引擎自动添加）。
- **人物**：圆润的脸、大而黑的眼睛（带两个高光）、小鼻子小嘴；服装简洁，纹样只出现在领缘、袖口和下摆。动作克制，眨眼、呼吸、口型都按“一拍二”（12fps）跳动，保留手绘的顿挫感。
- **母题**：标题“天幕”既是游牧民的帐幕，也是星空。开场和结尾优先使用 `bg.nightsky`（星空、北斗、银河）或 `bg.yurt_interior`（从陶脑天窗看见星星）。

### 历史细节（容易出错）

- **汉服右衽**：交领从观众视角看呈“y”字，左襟压右襟。引擎的 `robe: "han"` 已经画对，**不要对汉人角色使用 `flip`**（会变成左衽）。用 `look` 控制视线方向。
- **游牧民族左衽**：`robe: "nomad"` 自动镜像。
- **汉代城门**是平顶过梁式门道，不是拱门；`bg.citygate` 已按此绘制。
- **冕旒**只属于皇帝（正式场合）；官员戴进贤冠（`headwear: "guan"`）；武士戴赤帻（`"ze"`）。
- 地图方位：**西在左，东在右，北在上**。向西行进的队伍要 `flip: true`（马头朝左）。

## 2. 叙事

- **一集 2～5 分钟**，8～16 个场景。每个场景 1～4 句台词。
- **旁白为主，对白点睛**：旁白交代史实，人物台词只在戏剧性时刻出现，每句不超过 25 字。
- **忠于史料**：引用史书原话时注明出处（可用 `text.quote`），推测性的情节用旁白语气标明（“或许”“据说”）。年代、地名、人名要准确。
- **节奏**：开场用一个画面 + 一个问题抓住观众（≤15 秒），然后进入标题；中段地图与人物戏交替；结尾回到开场的意象，用一句史书原文收束。
- **字幕**每句不超过两行（约 40 字），长句拆开。

## 3. 声音

- **配音**：Gemini 3.8 TTS（`gemini-3.8-flash-tts`，配额用完自动换 `gemini-3.8-flash-lite-tts`）。旁白用沉稳的男声（`Charon`）或温暖的女声（`Sulafat`），每个角色固定一种音色。**角色气质主要靠选音色**：实测把中文语气提示（“用……的语气说：”）和台词一起送进去，模型会把提示原样念出来，所以默认只送台词。`style` 记录角色的语气设定；确实需要特别语气时给该角色加 `"direct": true`，会改用英文导演备注（偶有误读，由校对兜底重录）。
- **多音字/古地名**：`src/gemini/pronounce.js` 里有默认读音表（单于、月氏、大宛、龟兹、冒顿……）；剧本中的 `pronunciations` 可以补充；个别句子可以用 `say` 字段单独改写读音。
- **校对**：每句配音生成后，由专用听写模型 `gemini-3.5-transcribe` 逐字转写，程序比对台词（数字读法归一），多读、漏读、读出提示语的版本自动重录，最多 3 版。注意通用对话模型听写时会自动省略“用……的语气说”这种话，不能用来校对。`npm run check -- <剧集>` 查看汇总。
- **配乐**：Lyria 3（`lyria-3-pro-preview`）按“音乐段落”生成，时长与画面对齐。用英文描述乐器、情绪和速度，固定加上 *no vocals*。民族乐器（古筝、箫、二胡、琵琶、编钟）+ 小型弦乐，是最接近原作配乐质感的组合。
- **其他语言版本**：英文旁白按每秒约 2.7 个词控制句长，每句字幕不超过两行（约 110 个字符）；人名地名用不带声调的拼音（Zhang Qian、Xiongnu、Chang'an），读不准的在覆盖层 `pronunciations` 里改写；数字写成希望被读出的样子（"around 138 BC"）。
- **环境音**：`ambience` 可选 `wind`、`fire`、`night`、`sand`，由程序合成，音量很低。
